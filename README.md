## 📝 Todo App
A simple and efficient To-Do List application that allows users to Create, Read, Update, and Delete (CRUD) tasks. The data is stored and managed using PostgreSQL, ensuring real-time updates.

🚀 Features

✅ Add new tasks 📌

✅ Mark tasks as completed ✅

✅ Update tasks 🖊️

✅ Delete tasks ❌

✅ Data persistence with PostgreSQL 🗄️

✅ User-friendly interface with EJS & JavaScript 🎨


🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript, EJS

Database: PostgreSQL
